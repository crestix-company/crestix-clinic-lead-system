# 年齢判定ロジック

医籍登録年は卒業年ではありません。本アプリは医籍登録年と、登録時年齢の仮定分布から年齢を推定します。モデルは営業リストの選別に使う初期仮定であり、実年齢や、実測で校正済みの個人の年齢確率ではありません。

## 計算

入学時年齢を A、在学中の遅延年数を D、国家試験の遅延年数を N とすると、登録時年齢 R = A + 6 + D + N です。現在年を Y、医籍登録年を T として、推定年齢は Y − T + R です。

各分布を独立と仮定し、全組み合わせの確率を掛け合わせ、同じ登録時年齢に合算します。乱数は使わず、同じ設定・基準日なら同じ結果になります。

59歳以下確率 = 各組み合わせについて「Y − T + R ≤ 59」を満たす確率の合計。

丸める前の確率が0.50以上なら59歳以下、0.50未満なら60歳以上と判定します。登録年が未取得・不正・未来なら、不明になります。

## 編集場所

`config/age_model.yml` に以下を置いています。

- 入学年齢：18、19、20、21、22歳以上。
- 在学中の遅延：0、1、2年以上。
- 国試の遅延：0、1、2年以上。
- 6年の在学年数、59歳の基準、50%の閾値、分位点。
- 「以上」カテゴリの内訳。再受験・社会人入学の長い裾を含めて変更可能。

最初の3分布はユーザー提示値です。入学年齢の合計0.999は丸め差として正規化します。誤入力を隠さないよう、合計1との差が0.005を超える設定、負の値、NaNなどは拒否します。

22歳以上の内訳、2年以上の遅延の内訳はMVPで置いた追加仮定です。根拠のある統計から更新するまでは、推定結果を個人の事実として扱いません。

## 出力と解釈

中央値は50%分位、下限は5%分位、上限は95%分位です。上下限は最小値・最大値でも、個人に対する保証区間でもありません。確認用Excelには、登録年、確率、判定理由、モデルの全設定とSHA256を残します。

2026年を基準にした初期モデルでは、1992年登録で59歳以下となる確率は約63.47%です。18歳入学・遅延合計1年以下、または19歳入学・遅延なしがこの条件に当たります。1991年登録では約29.58%になります。

誕生日や登録月が不明なため、推定はユーザー指定の年単位の式です。受験浪人・留年・国試浪人の相関、大学別・登録世代別の違いは未反映です。母集団統計の新卒合格率を、そのまま過去の登録医師の構成比と見なせるとは限りません。

## 同姓同名

医籍データの本人特定を先に行います。複数候補・異なる登録年・別の候補IDがある場合は年齢を計算しません。複数候補が同じ登録年でも `candidate_count=2` 以上なら要確認です。氏名だけで先頭の検索結果を選びません。

公式情報：厚生労働省「医師等資格確認検索」の[ご利用上の注意](https://licenseif.mhlw.go.jp/search_isei/html/readmefirst.htm)と[Q&A](https://licenseif.mhlw.go.jp/search_isei/html/qa.htm)を確認。公表項目は職種・氏名・性別・登録年等で、氏名の完全一致が必要です。
