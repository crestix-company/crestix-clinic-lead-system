# HP調査の誤判定修正（2026-09-14）

## 対象となった不具合

- アイクリニック東京 サピアタワーで求人サイトを公式HPと判定し、そのサイト自身のSNSや他科の情報を取り込んだ。
- 武蔵小金井さくら眼科で大同生命の医療機関検索ページを公式HPと判定した。
- 眼科の「レーザー治療」を皮膚科の根拠に使った。
- 再調査で公式HPを確認できなくなっても、前回の治療カテゴリなどが現行結果に残った。

## 修正内容

1. 上記の求人・医療機関検索サイト、および確認した関連検索サイトを公式HP候補から除外する。移転先が該当サイトの場合も公式HPとして採用しない。
2. 除外したページからHPランク・治療カテゴリ・HP上のSNSシグナルを算出しない。
3. 汎用語「レーザー治療」を皮膚科キーワードから外す。緑内障レーザー治療、ニキビ・シミ治療などの具体的な判定は継続する。
4. 正式名・電話番号で公式HPを確認できなかった場合だけ、法人名を除いた医院名と所在地で1回補完検索する。Tavilyは1医院最大2回、従来の月間・調査上限と再開キャッシュを使用する。候補の本人確認条件は変更しない。
5. HP再調査で未発見・要確認・エラーとなった場合、旧HP由来の自動判定と現行の取得ページを消去する。過去の調査履歴、元CSV・UUID、手動修正、EPARK、独立して確認した外部媒体のシグナルは保持する。

## Windowsでの適用

1. アプリを起動した黒い画面で Ctrl+C を押して停止する。
2. `update_hp_research_fix.py` を、使用中の `app_v2.py` と同じフォルダーに置く。
3. そのフォルダーをエクスプローラーで開き、アドレス欄に `cmd` と入力して Enter。
4. 次を1回実行する。

```bat
py -3 update_hp_research_fix.py
```

更新成功を確認してから起動する。

```bat
.\.venv\Scripts\python.exe scripts\launch_v2.py
```

更新プログラムは変更前のコードを `code_backup_hp_research_*` に保存する。想定外のコード変更がある場合は上書きせず停止する。データベースは更新時には変更しない。

## 5件の再調査

「サンプルモード」をオフにし、「自動情報収集」で以下を指定する。

| 項目 | 設定 |
|---|---|
| 現存クリニックのみ | オン |
| HP確認済みのみ | オフ |
| 既存UUID | あり |
| 都道府県 | 東京都 |
| その他の絞り込み | 未選択・指定なし・オフ |
| 調査内容 | 公式HPの発見・内容調査 |
| 今回の医院数 | 5 |
| 今回の検索上限 | 10 |
| 1医院の最大HPページ数 | 20 |
| 強制再調査 | オン |

Tavilyキーをアプリの入力欄に入れ、「自動調査を開始」を1回押す。今回は完了済み5件の再検証なので、強制再調査をオンにする。以前の完了済みジョブを再開する操作ではない。

再統合・CSVの再アップロードは不要。更新ファイルの実行だけでは、過去の誤った調査表示は変わらない。再調査で置き換わる。

## 検証の範囲

Linux・Python 3.12の自動テスト222件で確認。求人サイトの除外、眼科レーザーの分類、再調査時の古い結果の除去、元レコード・手動修正・独立した媒体情報・EPARK・履歴の保持、検索上限での停止と再開を含む。検索と取得はテスト用応答を使用する。

公開HPの内容は閲覧確認したが、Tavilyの実APIキーは検証環境にない。Windows実機および利用者の保存DBでの実調査は、上記の手順で確認する。
