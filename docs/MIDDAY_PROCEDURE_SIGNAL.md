# 昼の検査・手術専用枠の加点（2026-09-15）

医院のHPに「通常の午前診療と午後診療の間に、検査・手術の専用枠を設けている」と分かる時間表がある場合、集客投資シグナルに「昼の検査・手術専用枠」を追加する。

## 判定例

| 時間 | 内容 |
|---|---|
| 9:00～12:00 | 午前診療 |
| 13:00～15:00 | 検査・手術専用 |
| 15:00～18:00 | 午後診療 |

この例は1点。YouTube公式運用など別のシグナルがもう1つあれば、合計2点で「アツい」。複数曜日・複数ページで同じ専用枠を見つけても、この項目は1点のみ。

## 自動判定する条件

- 本人確認を通過したHPの調査で取得した、文字の時間案内またはHTML表を利用する。
- 同じ時間表・同じ曜日に午前の通常診療、検査・手術枠、午後の通常診療の3つを確認する。
- 午前診療の終了後に専用枠が始まり、その終了後に午後診療が始まる。
- 内視鏡検査、胃カメラ、大腸カメラなどの専用枠も含める。
- 空白の休憩時間が前後にあっても、専用枠が通常診療の間に収まれば対象。

「検査・手術に対応」とだけある場合、専用枠の開始・終了が不明な場合、通常診療と重なる場合、午後が手術のみでその後の通常診療がない場合は、自動加点しない。休止・実施なし・予約受付・相談だけの枠も対象外。

画像・PDFのみの時間表や意味を確認できない記号・脚注は、自動で推測しない。現時点ではOCRを追加していない。目視で確認できた場合は、医院詳細の手動修正から「集客投資シグナル」を選び、この項目を追加できる。変更理由に時間帯・曜日を記入する。

## 画面と保存

- 「シグナル一覧」に表示され、既存のシグナル数・アツさに反映される。
- 「必須の集客投資シグナル（選んだものすべて）」で、この条件の医院を絞り込める。
- 詳細に根拠URL、午前・専用枠・午後の時間帯、曜日、根拠文を保存する。
- HPランク・年齢推定の基準、コムデスクA～ABの28列、既存UUID・元データの仕様は変更しない。
- 通常のHP調査で取得した内容を使い、この判定専用のTavily検索は追加しない。

## Windows更新

今回のアップデータは前回のHP誤判定修正も含む。前回修正の適用前・適用後の両方に対応する。対応外のコード変更がある場合は上書きせず停止する。

1. 起動した黒い画面で Ctrl+C を押してアプリを停止する。
2. `update_midday_procedure_signal.py` を、使用中の `app_v2.py` と同じフォルダーに置く。
3. そのフォルダーのエクスプローラーのアドレス欄に `cmd` と入力して Enter。
4. 次を1回実行する。

```bat
py -3 update_midday_procedure_signal.py
```

成功したら起動する。

```bat
.\.venv\Scripts\python.exe scripts\launch_v2.py
```

保存済みの医院へ自動判定を反映するには、「自動情報収集」で公式HPの発見・内容調査を選び、対象医院の「強制再調査」をオンにして開始する。まずは東京都・既存UUIDあり・現存クリニックのみオン・HP確認済みのみオフ・5医院・検索上限10・最大20ページで確認する。CSVの再取り込み・再統合は不要。

## 検証

自動テスト260件に成功。通常枠との重複、異なる曜日の取り違え、休診・休止、時間不足、画像だけの表示、全角表記、結合セル、重複加点、1点／2点の判定、保存と絞り込みを含む。Linux・Python 3.12でテスト用HTMLを使用。Windows実機と実医院の時間表による確認は別途必要。
